# ESP32-C3 久坐健康管家微信小程序

小程序通过 BLE 直接连接附近的 `ESP32C3-Haptic`，显示今日累计久坐时间、
完成轮次、提醒次数和上一轮响应结果，并可开启/静音提醒、调节音量和设置
三级提醒阈值，以及马达二级震动频率。设置与每日汇总保存在设备 NVS。手机和 ESP32 必须在蓝牙
通信距离内；微信小程序不能通过互联网远程连接 BLE。

设备检测到入座持续 30 秒后开始本轮计时；三级提醒阈值按本轮实际入座时间
累计计算，默认 30/60/90 分钟。三级后每 60 分钟重复三级提醒。离座超过
1 分钟才结束本轮，短暂离座不结束本轮且离座期间暂停计时。提醒声音静音时，
传感器和计时仍继续。设备上电后播放一次轻微屁。
提醒次数只累计实际播放成功的久坐提醒；静音期间久坐时长和轮次仍统计，
但不会补播已经静音错过的提醒。上一轮在至少播放过一次提醒后有效离座记为
“已响应”；如果本轮未播放提醒则显示“无提醒”。

## 在微信开发者工具中运行

1. 在微信公众平台注册小程序，并取得 AppID。安卓和 iPhone 均通过微信 BLE
   API 直接连接设备；不需要 Web Bluetooth 或单独安装应用。
2. 用微信开发者工具导入本目录 `miniprogram/`。
3. 将 `project.config.json` 中的 `touristappid` 替换为小程序 AppID。
4. 编译后分别在 Android 手机和 iPhone 上预览验证。手机开启蓝牙，并允许
   微信使用蓝牙/附近设备权限；部分 Android 系统还要求允许定位权限并开启
   系统定位服务才能扫描 BLE。iOS 自动协商 BLE 数据长度，小程序只在 Android
   上请求设置 MTU。
5. 将更新后的 ESP32-C3 固件重新烧录并上电，在页面点击“连接设备”，选择
   `ESP32C3-Haptic`，连接后修改参数并保存。固件会在 BLE 扫描响应中广播控制
   服务 UUID，便于 iPhone/微信识别目标设备；旧固件不会广播这个标识。

系统蓝牙设置里的“配对”不是连接小程序的必要步骤。小程序会通过微信 BLE
API 建立 GATT 连接。设备名未出现时，请确认固件启动日志包含
`Advertising as ESP32C3-Haptic`，并检查手机蓝牙权限。
如果提示 `openBluetoothAdapter:fail already opened`，这是蓝牙适配器已打开，
小程序会继续扫描。小程序只显示名称或广播服务 UUID 能匹配的 ESP32-C3，不会
列出附近不相关的未命名设备。若仍搜不到，请确认设备已烧录更新后的固件、
正在广播，并检查微信的蓝牙/附近设备权限。

每级触发时间需为 1–1440 分钟，并按顺序非递减。小程序连接设备时会将手机
本地日期同步到设备，用于自然日统计；设备无需联网或配置 NTP。小程序会将
BLE 命令拆分为不超过 20 字节的数据包，以兼容未协商较大 MTU 的手机。修改
音量、提醒时间或震动等级后必须点击“保存设置到设备”，并等待设备状态确认；
两级震动各提供两个固定档位：一级（50 Hz/振幅 80 或 55 Hz/振幅 70）、二级（60 Hz/振幅 70 或 60 Hz/振幅 80），选择档位后点击保存写入设备 NVS；上电短震为独立固定短震，不受档位影响。
阈值按当前
坐姿轮次的累计坐姿时间计算，改值不会重置已累计时间或重播已经触发过的提醒。
BLE 控制命令包括 `AUDIO <volume> <delay1_ms> <delay2_ms> <delay3_ms>`、
`POWER ON|OFF`、独立触发阶段提醒的 `REMINDER 1|2|3`、同时停止扬声器和马达的 `STOP ALL`、`MOTOR <blast_amplitude> <blast_frequency_hz> <awkward_amplitude> <awkward_frequency_hz>`、
`CLOCK <local_epoch_seconds>` 以及手动振动 `VIBRATE <amplitude> <frequency_hz> <duration_ms>`
（幅度 1–90、频率 40–200 Hz、时长 100–5000 毫秒，触发后自动停止）和 `VIBRATE STOP`。
固件接受 `REMINDER 1|2|3` 命令以独立于久坐时间触发对应音效和震动，不计入提醒统计；
提醒声音静音时不会触发。小程序提供阶段一、二、三的独立触发按钮；设备正在播放其他音效时会跳过本次触发。“同时停止马达和扬声器”仅停止当前输出及待执行振动，不改变提醒声音开关。“手动振动”卡片可独立驱动马达，用于手动测试。

## 使用记录

设备离线时也会独立记录每次使用：入座开始、久坐完成（含实际久坐时长、
提醒次数与是否响应）、每次实际播放的提醒（级别），以及异常中断（久坐中
断电/复位，含中断原因与已坐时长）。连接设备后，小程序会通过历史特征值
自动批量同步这些离线记录并保存在手机本地（`wx` 存储），在“使用记录”
卡片中按时间倒序展示；下次连接只同步新增记录，不会重复。
未连接过手机（设备尚未对时）时，记录时间显示为“设备未对时”，但仍会按
发生顺序保留并同步。
